# 供应链需求预测系统

基于时间序列分析 + 大语言模型的零售门店销售预测与备货建议系统

## 项目简介
使用厄瓜多尔连锁超市真实销售数据（300万条），构建需求预测系统：
- 梯度提升模型预测未来销售量
- AI根据预测结果自动生成备货建议
- 覆盖54家门店、33个商品类别

## 技术栈
- Python / Pandas / Numpy
- Scikit-learn（梯度提升回归）
- 时间序列特征工程
- ZhipuAI GLM-4（大语言模型）

## 数据集
Store Sales - Time Series Forecasting (Kaggle)
- 300万条销售记录
- 时间跨度：2013-2017年

## 主要结论
- 模型MAE：339单位
- 成功捕捉销售的周期性和趋势性规律
- AI备货建议可降低库存积压和缺货风险
